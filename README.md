# care-report-generator

訪問介護申し送り文作成ツール

ケア内容をチェックボックスで選択するだけで、ケア報告書と「書き方・並び順が異なる15種類の申し送り文」を自動生成する3ページ構成のツールです。ビルド不要・サーバー不要で、ブラウザで `index.html` を開くだけで動作します。

## 使い方

1. `index.html` をブラウザで開く（またはローカルサーバーで配信）
2. **Step1（ケア内容選択）**：利用者情報を入力し、実施したケア項目にチェック。チェックすると詳細入力欄（摂取量・状態など）が表示されます
3. **Step2（報告書プレビュー）**：選択内容から自動生成されたケア報告書を確認・編集・コピー
4. **Step3（申し送り15種類）**：同じケア内容から、書き方・並び順が異なる15種類の申し送り文を自動生成。用途に合わせて選び、個別にコピーできます

入力データはブラウザの `localStorage` に保存され、3ページ間で引き継がれます。

## ファイル構成

- `index.html` / `report.html` / `handover.html` … 3ページそれぞれの画面
- `css/style.css` … 共通スタイル
- `js/itemDefs.js` … ケア項目・カテゴリの定義（マスターデータ）
- `js/storage.js` … ページ間のデータ引き継ぎ（localStorage）
- `js/reportBuilder.js` … ケア報告書テキストの生成
- `js/handoverTemplates.js` … 申し送り15種類の生成ロジック
- `js/step1.js` / `js/step2.js` / `js/step3.js` … 各ページの画面制御
