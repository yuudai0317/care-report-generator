# care-report-generator

訪問介護申し送り文作成ツール

## 縦書きテキストエディタ

Microsoft Word のように、用紙・余白・書式を決めて**縦書きの文書**を作成できるエディタです。
ビルド不要・依存ライブラリなしの静的ページなので、`index.html` をブラウザで開くだけで使えます。

```
index.html                 画面の構成
assets/css/editor.css      画面と印刷のスタイル
assets/js/editor.js        エディタ本体
```

### 使い方

`index.html` をブラウザで直接開くか、ローカルサーバー経由で開きます。

```bash
# どちらでも可
xdg-open index.html
python3 -m http.server 8000   # → http://localhost:8000/
```

対応ブラウザは Chrome / Edge / Firefox / Safari の最新版です。
縦書きの組版に CSS の `writing-mode` を使っているため、モダンブラウザが必要です。

### できること

**書式（ホームタブ）**

- フォント（明朝体・ゴシック体）、サイズ、太字・斜体・下線・取り消し線
- 文字色、蛍光ペン、書式のクリア
- 上揃え・中央揃え・下揃え・両端揃え、箇条書き、段落番号、インデント
- 行間と字間

**縦書き専用の書式**

| 機能 | 内容 |
| --- | --- |
| ルビ | 選択した文字にふりがなを振る（`<ruby>`） |
| 縦中横 | 半角数字などを 1 マスに横に組む（`text-combine-upright`） |
| 圏点 | 傍点を打って強調する（`text-emphasis`） |
| 割注 | 小さな二行書きの注記 |
| 正立 | 半角文字を縦向きのまま並べる |

**レイアウト（レイアウトタブ）**

- 縦書き / 横書きの切り替え
- 用紙サイズ（A4・B5・A5・B4・レター・はがき）と印刷の向き
- 余白（プリセット4種 + mm 単位のユーザー設定）
- 原稿用紙モード：20字 × 20行 が収まる正方形のマス目に組みを自動調整

**編集・ファイル**

- 元に戻す / やり直し、検索と置換（すべて置換）
- 改ページの挿入、日付（令和・西暦）、時刻、区切り線、記号パレット
- 自動保存（ブラウザの localStorage、約1.2秒ごと）
- 保存 `.json` / 書き出し `.doc`（Word）・`.html`・`.txt` / ファイルのドラッグ＆ドロップ読み込み
- 印刷・PDF 出力

### ショートカット

| キー | 動作 |
| --- | --- |
| `Ctrl+S` | 保存（.json） |
| `Ctrl+O` | 開く |
| `Ctrl+P` | 印刷 |
| `Ctrl+F` / `Ctrl+H` | 検索と置換 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直し |
| `Ctrl+Enter` | 改ページ |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | 太字 / 斜体 / 下線 |
| `Ctrl+Alt+N` | 新規作成 |

### 設計上の注意

**ページの見え方**
画面上の本文は 1 本の長い流れとして持ち、ページの区切りは薄い罫線で示します
（Word のように 1 枚ずつ独立した紙が並ぶ形ではありません）。
ページ数・改ページ・印刷結果はすべてこの同じ計算にもとづくため、画面と印刷は一致します。

**印刷**
縦書きは行が左へ進むので、ブラウザ既定のページ分割（上から下）とは向きが合わず、
そのままでは 1 ページ目しか出力されません。
そのため印刷時は本文を 1 ページ分ずつ切り出した `.print-page` を組み立て直しています。
用紙サイズと余白は `@page` に反映されるので、印刷ダイアログでは
用紙サイズを「実際のサイズ」、余白を「なし」にしてください。

**本文の書式適用について**
`ruby` 要素や縦書き用の `span` は、ブラウザの編集コマンド（`execCommand('insertHTML')`）が
「不要な要素」とみなして取り除いてしまうため、DOM を直接組み替えて適用しています。
これに合わせて元に戻す／やり直しは、ブラウザ標準の履歴ではなく自前のスナップショット履歴で
一元管理しています（日本語入力の変換中は記録しません）。

**フォント**
縦書きの字送りは選んだフォントに依存します。原稿用紙モードでマス目に揃えたい場合は、
ＭＳ 明朝・ＭＳ ゴシックなどの等幅フォントを選んでください。
日本語フォントが 1 つも入っていない環境では、字送りが崩れることがあります。

**Word 形式の書き出し**
`.doc` は Word が読める HTML として書き出し、縦書きは `mso-layout-flow-alt` で指定しています。
再現の度合いは Word 側の対応範囲に依存するため、完全な .docx 互換ではありません。

**フォントの読み込み**
Noto Serif JP / Noto Sans JP を Google Fonts から読み込みますが、
オフラインでも端末側のフォントにフォールバックして動作します。
