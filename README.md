# care-report-generator

訪問介護申し送り文作成ツール

## 縦組 — 縦書きテキストエディタ

`index.html` 一枚で動く、日本語縦書き用のテキストエディタです。ビルド不要・依存ライブラリなしで、
ブラウザで開くだけで使えます。

### 使える機能

| 機能 | 説明 |
| --- | --- |
| 縦組／横組 | `writing-mode: vertical-rl` による本式の縦書き。ワンボタンで横組に切り替え |
| 原稿用紙 | 升目を背景に敷き、行数ごとにページ区切りの朱線を引く |
| ルビ | 選択して「ルビ」→よみを入力。`<ruby>` で挿入（`<rp>` 付きなのでコピペしても読みが壊れない） |
| 傍点 | `text-emphasis: filled sesame` によるゴマ点 |
| 縦中横 | 半角数字などを正立させる（`text-combine-upright`） |
| 太字・傍線・書式消し | ルビ／傍点／縦中横もまとめて解除できる |
| 体裁 | 字／行・行／頁を数値で指定。原稿用紙 20×20、投稿用 40×40、文庫判 42×16 などのプリセット付き |
| 文字サイズ・行間 | 4段階の文字サイズ、3段階の行間（原稿用紙モードでは升目に合わせて固定） |
| 検索・置換 | 順送り検索、1件置換、すべて置換 |
| 集計 | 字数・行数・頁数・原稿用紙換算枚数・段落数をリアルタイム表示 |
| 自動保存 | 入力の 0.8 秒後に localStorage へ保存。次回起動時に続きから開く |
| 開く | `.txt` / `.html` を読み込み。青空文庫記法のルビ・傍点はマークアップへ復元する |
| 書き出し | `.txt`（青空文庫記法・UTF-8 BOM 付き）と `.html`（体裁を埋め込んだ単体ファイル） |
| 印刷 | A4 縦。UI と升目を落として本文だけを刷る |
| 集中モード | 書式バーを隠し、上段バーを淡くする |

### キーボード

- `Ctrl/⌘ + S` — 直ちに保存
- `Ctrl/⌘ + F` — 検索・置換を開く
- `Ctrl/⌘ + Shift + R` — ルビ
- `Ctrl/⌘ + Shift + E` — 傍点
- `Esc` — ダイアログ／検索バー／集中モードを閉じる

### 青空文庫記法

`.txt` の読み書きで次の記法を相互変換します。

```
｜吾輩《わがはい》は猫である。
頓と見当［＃「見当」に傍点］がつかぬ。
```

ルビは `｜` 付き・漢字直後の `《》` の両方を読み込みます。書き出しは常に `｜` 付きです。

### 動かす

ローカルではファイルを開くだけで動きます。

```sh
open index.html          # macOS
xdg-open index.html      # Linux
```

### 公開（GitHub Pages）

`.github/workflows/pages.yml` が `main` への push で Pages へデプロイします。初回のみ、
リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に
変更してください。以後 `https://yuudai0317.github.io/care-report-generator/` で公開されます。

### 組版についての注意

升目にきっちり合わせるには、和文の送り幅が 1em のフォントが要ります。Hiragino Mincho ProN /
Yu Mincho / MS PMincho のいずれも無い環境向けに Noto Serif JP を Google Fonts から読み込んで
いるため、Windows・macOS・Linux・iOS・Android のいずれでも升目が揃います。
